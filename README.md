# Legacy personal website redirects

The active personal website is [sonukapoor.com](https://sonukapoor.com/).
This repository stays published through GitHub Pages to redirect legacy links.
Do not disable Pages or assign the new site's custom domain here.

Each legacy HTML page uses a canonical URL, immediate HTML refresh, JavaScript
`location.replace` (preserving query strings and fragments), and a visible link.
GitHub Pages serves these as HTML redirects, not HTTP 301 responses.
Unknown URLs use `404.html` to redirect to the new homepage; their initial HTTP
status remains 404. Binary downloads and assets remain available at their existing URLs.
